# Computational Molecular Dynamics & Peptide Self-Assembly

## Research Overview
This research explores the fundamental nanoscale mechanics that govern hydrogel network stability and cross-linking behaviors. By conducting high-throughput all-atom simulations on customized pentapeptide variants, the work builds structural insights into how minor sequence modulations alter macro-scale polymer assembly.

## Technical Contributions
* **High-Throughput Testing:** Set up and configured initial topology and coordination files for **over 100 simulation scenarios**, ensuring a controlled baseline for parsing thermodynamic properties.
* **Cluster Automation:** Managed execution streams via **SLURM batch queues** on specialized high-performance computing (HPC) nodes.
* **Post-Processing Arrays:** Penned Python processing scripts to handle massive coordinate file streams, computing structural contact maps and isolating specific frame ranges for visualization.
* **Academic Review:** Visualized multi-state trajectory frames in VMD for a manuscript currently under peer review, and presented slide decks detailing structural data trends during cross-laboratory project assemblies.
